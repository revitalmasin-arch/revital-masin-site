# אתר תדמית - רויטל מאסין

אתר אישי חד-עמודי (One Page) לרויטל מסין, מהנדסת פרויקטים.

## תוכן האתר
- **אודות** - מהנדסת פרויקטים יצירתית 
- **חוזקות** - ניהול פרויקטים, יצירתיות, פתרון בעיות, הובלה
- **טיולים** - אהבה לגילוי עולם ותרבויות חדשות
- **משפחה** - שלושת הבנים שלי
- **יצירת קשר** - פרטי התקשרות ורשתות חברתיות

## טכנולוגיה
HTML + CSS טהורים (Vanilla), ללא תלות בספריות חיצוניות. עיצוב רספונסיבי, RTL בעברית.

## הרצה מקומית
פשוט לפתוח את הקובץ `index.html` בדפדפן.

## פריסה (Deploy)
ניתן לפרוס בקלות עם GitHub Pages, Netlify או Vercel.
